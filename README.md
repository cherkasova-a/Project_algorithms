# Система распределения фаз контейнерных перевозок

Программа предназначена для автоматической обработки статусов перемещения контейнеров и их классификации согласно пятифазной модели мониторинга грузов.

## Архитектура решения

Проект реализует двухуровневую логику обработки данных в зависимости от оператора перевозки:

1. **Персональные алгоритмы:** Набор из 12 специализированных алгоритмов, адаптированных под специфику статус-кодов конкретных морских линий (Maersk, MSC, CMA-CGM и др.).
2. **Универсальный алгоритм (algorithm_ALL):** Общий модуль обработки, используемый для анализа событий линий, не имеющих персональных скриптов.

## Структура репозитория

* **algorithms/** — библиотека программных модулей. Содержит 12 персональных парсеров и универсальный алгоритм `algorithm_all_uni.py`.
* **data/** — наборы тестовых данных (CSV, UTF-16), выгруженные из ClickHouse. Каждый файл содержит 1000 строк реальных логов по конкретной компании.
* **test.py** — основной скрипт валидации. Выполняет проверку последовательности фаз и классифицирует ошибки на два типа:
    * *Пропуск фазы (Skip):* некорректный скачок через этап (например, с 1 на 3).
    * *Обратный ход (Reverse):* уменьшение порядкового номера фазы в цепочке событий.
* **comparison.py** — модуль сравнительного анализа. Сопоставляет результаты персональных и универсального алгоритмов для выявления расхождений. Результаты сохраняются в `comparison_diff_report.csv`.
* **algorithm.py** — главный модуль маршрутизации данных. Скрипт берет сырой JSON, извлекает название морской линии из поля `['result']['summary']['company']['name']` и проверяет его по словарю поддерживаемых компаний. Если линия найдена, вызывается соответствующий персональный алгоритм. Если линии нет в словаре (новая или редкая компания), поток данных автоматически перенаправляется на универсальный модуль `algorithm_ALL`.
